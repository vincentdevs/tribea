# Tribea

## Brand Guidelines (applies to every branded artifact)

Whenever you build or rework anything branded for Tribea (content, social posts, slides, designs, websites, pages, apps, invoices, documents), follow the brand guidelines below. They are imported into every session so they are always in context.

Use only the approved typefaces in `fonts/` and the colors listed in the guidelines. For any change to the website, also read `tribea-website/README.md`, which lists the decisions locked with the client, and for any new page or artifact read `docs/GOTCHAS.md` before starting and check the result against it before handing it over. In code, import `styles/fonts.css` and `styles/tokens.css` and reference the CSS variables (`--font-heading`, `--accent`, `--text` and so on) rather than hard-coding font names or hex values. There is no dark mode.
