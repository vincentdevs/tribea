# Tribea

Tribea is a political communication agency in Switzerland that brings the latest campaign and communication technology to parties, candidates, committees and administrations, and uses it privacy-first and within Swiss law.

| Folder | What it holds |
|---|---|
| `docs/BRAND_GUIDELINES.md` | Typography, colours and logo rules for every branded artifact |
| `docs/PRODUCT.md` | What the website is, who it serves and the quality it is measured against |
| `fonts/` | The two approved typefaces, Newsreader and Lato, with their licences |
| `styles/` | Colour tokens and font declarations for any web project |
| `logo/` | The wordmark and the symbol as SVG |
| `tribea-website/` | The website in French, German, Italian and English |
